\section{Design of HALO}
\label{sec:design}

\subsection{System Overview}
\label{sec:overview}
\label{sec:requirements}

HALO separates representation learning from evidence-based classification
(Figure~\ref{fig:overview}). Phase A trains a sensor encoder without activity labels. The encoder is
then frozen and used to build a versioned memory. At inference, a closed-form evidence path compares
query and memory rows. The only fitted component in this path is a small admissibility gate that
maps a sensor description and a candidate concept to one scalar. There is no relational decoder,
learned retrieval projection, or deployment-specific output head in the active system.

  \setlength{\belowcaptionskip}{-5pt}
  \input{figures/fig_overview.tex}
  \caption{\textbf{HALO end to end.} Phase A learns one sensor representation without activity
  labels. A versioned bank stores frozen per-patch, per-sensor rows. Classification applies hard

  Enrollment appends labeled rows; it does not update parameters.}
  \label{fig:overview}

For a window containing an accelerometer and gyroscope, the spectral front end first produces
features for each scalar axis. The three axes of each modality are then folded into one token per
patch and physical sensor. Frozen text describes what the sensor was declared to be, while a
separate vector records activity-invariant acquisition measurements. A transformer contextualizes
these tokens over physical time and across sensors. The memory stores the resulting sensor rows
with labels and provenance.

\subsection{Sensor-Granular Tokenizer}
\label{sec:tokenizer_design}

\subsubsection{Frequency features in physical units}
\label{sec:filterbank}

For each channel patch, the tokenizer removes the mean after applying a validity mask, applies a
Hann window, and computes a zero-padded real DFT of size $S{=}256$. If the stored array rate is $r$,
bin $m$ represents $mr/S$ hertz. It then evaluates $K{=}32$ Gaussian filters whose centers are
logarithmically spaced from $0.3$ to $15$\,Hz and whose nominal bandwidth scales with center
frequency ($Q{=}4$). The construction is \emph{constant-$Q$-inspired}: the cited constant-$Q$
literature supports geometric center spacing~\cite{constantq,constantqfast}, while the Gaussian
weighting and its parameters are HALO design choices.

The tokenizer operates on the stored grid and avoids an additional interpolation step in the model
path. When a converter has already resampled a device stream, the stored rate still defines the DFT
coordinate, but the original acquisition rate bounds observability. The representation therefore
does not assert that different devices have identical filter responses; it only assigns the same
physical coordinate to corresponding bands.

For center $c_k$ and width $\sigma_k=c_k/(2Q)$, the observability mask is
\[
 o_k=\mathbf{1}\!\left[c_k+2\sigma_k\leq0.9r_{\mathrm{source}}/2\right].
\]
The patch-resolution flag is the clipped number of cycles in duration $D$,
$q_k=\min(1,c_kD)$. This is a heuristic indication of spectral support, not a theorem that one cycle
is sufficient. Unobservable bands and observed zero energy remain distinguishable.

The mean removed from the spectral path is retained as a signed per-axis low-frequency feature for
accelerometers. It can carry gravity and posture information. We do not attach the numerical
posture-separation claims from an earlier draft because their generating artifact is absent; the
ablation in Section~\ref{sec:pending_measurements} is the evidential test of this design choice.

\subsubsection{Folding axes into physical sensors}
\label{sec:sensor_grouping}

Each accelerometer or gyroscope is a three-axis physical sensor. HALO concatenates the three
per-axis patch tokens in fixed $x,y,z$ order, zeros invalid axes, appends a three-bit validity
vector, and projects the result to one token. Thus ``axis reads zero'' differs from ``axis absent.''
A six-channel accelerometer--gyroscope stream becomes two tokens per patch, while an
accelerometer-only stream becomes one. Axis-role text is unnecessary after folding because axis
identity is represented by its position inside the sensor token.

The augmentation stack respects this structure. One $SO(3)$ rotation is applied jointly to a triad
and to a co-located gyroscope. Sensor masking is permitted only when another modality at the same
placement remains visible; the model is never asked to reconstruct a wrist from an ankle or pocket.

\subsubsection{Declared descriptors and measured acquisition bias}
\label{sec:conditioning}

Each sensor receives two frozen artifacts. A 384-dimensional sentence embedding describes device,
modality, placement, gravity state, and whether a partner modality was present. A 14-dimensional
measurement vector contains seven standardized statistics and seven support bits: gravity
magnitude, gravity presence, high-band noise floor, quantization step, clipping fraction, native-to-
stored rate fidelity, and rest bias. These statistics are estimated on training subjects and, where
possible, quiescent windows; unsupported fields remain unsupported rather than being imputed as
measurements.

Separate learned MLPs project the two artifacts into the token width and inject them through gated
residuals. Keeping the artifacts frozen preserves their audit meaning. The representation may still
encode dataset provenance, so we measure dataset-identification accuracy and keep similarity in the
acquisition-statistics vector disabled in the active retriever unless a provenance guard shows it is
safe.

\subsubsection{Context encoder}
\label{sec:encoder}

The transformer encoder~\cite{transformer} has width 256, six layers, eight heads, and a frozen
all-MiniLM-L6-v2 text encoder~\cite{sbert}. Attention alternates over time within a sensor and across sensors at a patch;
padding and sensor masks exclude missing values. Rotary positions use elapsed seconds rather than
token indices~\cite{rope}. Each window is represented at two patch-duration resolutions. Pooling weights real
patch duration within a resolution and gives equal weight to active resolutions.

\subsection{Phase A: Label-Free Pretraining}
\label{sec:phaseA_design}

% See STALENESS.md sec. 2.
Phase A has two top-level objectives. Their coefficients are calibrated once at step 2,000 from
encoder-gradient norms and then fixed.

\textbf{Masked contextual prediction.} A student predicts contextual sensor tokens produced by an
exponential-moving-average teacher~\cite{byol,data2vec,ijepa}. Masking includes contiguous time
blocks and, when physically well posed, a complete modality at one placement. A descriptor-mask
event hides a sensor's text while leaving its signal and measured bias visible; an InfoNCE
retrieval loss~\cite{infonce}
then ranks the true frozen descriptor among the distinct descriptions in the batch. This term is
part of the JEPA objective family rather than a third top-level objective.

\textbf{Augmentation consistency.} VICReg~\cite{vicreg} aligns two physical augmentations of the
same window while maintaining feature variance and reducing covariance. It avoids declaring other
windows to be negatives when they may contain the same activity. Activity labels are not used in
either gradient path. Checkpoint selection uses subject-disjoint $k$-nearest-neighbor balanced
accuracy on the Phase-A validation subjects.

\subsection{Admissibility-Gated Evidence}
\label{sec:evidence_design}

\begin{figure}[t]
  \centering
  \setlength{\abovecaptionskip}{4pt}
  \setlength{\belowcaptionskip}{-4pt}
  \input{figures/fig_evidence.tex}
  \caption{\textbf{Active evidence path.} Compatibility and admissibility are applied before
  candidate-specific top-$k$ ranking. Enrolled rows vote only for the candidate to which the
  application bound them; corpus rows vote through label-text similarity. Per-sensor votes are
  summed.}
  \label{fig:evidence}
\end{figure}

\textbf{Bank.} The current schema stores one row per patch and sensor: a 256-dimensional feature,
the frozen sensor descriptor, acquisition measurements, label, subject, dataset, configuration,
recording event, time, and resolution. The bank is bound to the exact encoder checkpoint and schema.
Query-window, event, and subject identifiers are excluded where required by the evaluation
protocol. Enrollment adds rows whose episode-local candidate identity is explicit.

\textbf{Train-only resolvability measurement.} For every training sensor and concept with adequate
support, a subject-disjoint one-versus-rest $k$NN probe measures how well that sensor distinguishes
the concept. Chance balanced accuracy maps to zero. Accelerometers and gyroscopes are measured
separately, and simultaneous-placement contrasts are reported separately. Activity strings group
the measurement cells; they are not embedded by this probe.

\textbf{Admissibility gate.} A rank-$r$ bilinear model maps frozen sensor and concept text to one
weight:
\[
 u=Ae_s,\qquad v=Be_c,\qquad
 g(s,c)=\sigma\!\left(u^\top\Lambda v+b\right),
\]
where $e_s,e_c\in\mathbb{R}^{384}$ and $r{=}2$ in the active artifact. The low rank limits the
gate's ability to memorize literal stream--label cells. It is fitted only to the train-only
resolvability table. For text unlike the fitted sensor or concept supports, the prediction is
blended toward the table's neutral median rather than extrapolated confidently. Held-out
configuration, dataset, and concept folds are required to characterize generalization; the fitted
table itself is not validation evidence.

\textbf{Prediction.} For each query sensor, HALO performs the following operations in order.

\begin{enumerate}
  \item Hard compatibility removes rows with incompatible modality or gravity state. This step is
        label independent.
  \item The gate scores the query sensor and memory sensor against each candidate. Their geometric
        mean requires both sides to observe the concept. Rows below the veto threshold are removed
        \emph{before} top-$k$, so a rejected row frees its slot.
  \item Feature cosine ranks the surviving rows separately for each candidate. The active budget is
        64 rows per query patch and candidate. Similarity in the acquisition-statistics vector has
        weight zero in the reported artifact.
  \item An enrolled row votes for its bound candidate by identity. A corpus row votes through the
        rectified cosine between its stored label text and the candidate text; this is the only
        $k{=}0$ bridge.
  \item Votes are summed across the query's sensors. This fusion is closed form and does not infer
        one placement's signal from another.
\end{enumerate}

Setting every admissibility value to one gives the ungated identity-retrieval control. Prototype and
ridge classifiers use the same frozen representations and enrolled examples. Support removal and
cyclic support-label shuffling test whether an apparent enrollment gain actually uses the labeled
rows.

\textbf{Scope.} The active system does not include an unknown output, confidence calibration,
Core~ML export, an iOS application, or a public \texttt{predict()} API. Selective classification
would require truth-absent episodes and risk--coverage evaluation~\cite{selectiveclass}; evidential
deep learning is a distinct uncertainty method~\cite{edl} and is not evidence for the present
retrieval rule.
