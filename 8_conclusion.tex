\section{Conclusion}
\label{sec:conclusion}

HALO tests one proposition: acquisition configuration should calibrate evidence rather than be
normalized away. We build a sensor-granular encoder that defines frequency bands in physical hertz,
marks what a configuration cannot resolve, and learns without activity labels; we classify by a
transparent sequence of compatibility, admissibility, cosine ranking, voting, and sensor fusion; and
we enroll a new activity by appending rows to memory rather than updating parameters.

The proposition remains open, and we are explicit about why. The encoder and its memory are built,
but the admissibility gate is not yet fitted against them, so we report no recognition accuracy. The
more useful finding is structural: a two-sided admissibility score degenerates to a per-candidate
constant whenever enrollment and query share a configuration, so the obvious evaluation --- enroll
and query on the same device --- cannot express the mechanism at all. The next measurement follows
directly and needs no retraining: enroll on one device, query from another.
