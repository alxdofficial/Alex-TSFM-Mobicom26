
\section{Introduction}



% From diverse wearable devices to unified activity understanding. Consumer wearables vary widely in sampling rates, channel counts, and sensor placements, producing heterogeneous IMU signals. HALO maps all configurations into a shared IMU--text embedding space, enabling zero-shot, open-set activity recognition via cosine similarity---no per-dataset classifier needed.



Inertial measurement units (IMUs) are among the most widely deployed sensors in consumer electronics such as smartwatches and smartphones, enabling human activity recognition (HAR) for applications in health monitoring~\cite{mhealth}, rehabilitation~\cite{pamap2}, sports analytics~\cite{dsads}, and human--computer interaction. Yet nearly every such application is built essentially from scratch: teams collect a bespoke dataset, train a dataset-specific classifier, and hard-code a fixed sensor layout and label set. What the field lacks---and what vision has had in CLIP~\cite{clip} and language in general-purpose pretrained models---is a \emph{reusable} IMU foundation model that a developer can pick up and build on: one pretrained model that ingests whatever sensors a device exposes, recognizes the application's own activity labels without retraining, and runs both offline over a recording and as a live on-device stream.

Delivering such a model requires overcoming four barriers that have kept prior IMU models dataset-bound. First, \emph{sensing heterogeneity}: datasets differ substantially in sampling rates (20--100 Hz), sensor suites (3--45 channels spanning accelerometers, gyroscopes, and magnetometers at various body placements), and label vocabularies with inconsistently overlapping activity names. Second, \emph{open-set labels}: a deployment routinely names activities absent from training, so the model must recognize arbitrary label strings rather than a fixed class set. Third, the \emph{offline/online divide}: benchmarks assume a whole recording is available, whereas a phone or watch app needs low-latency, causal predictions from the same model. Fourth, \emph{trustworthy evaluation}: prior cross-dataset protocols entangle synonym ontologies and share subjects across splits, so reported gains often do not survive leakage-free testing.

Existing approaches address these barriers only in isolation. Self-supervised methods (LiMU-BERT~\cite{limubert}, CrossHAR~\cite{crosshar}) improve transferability but still require a closed-world classifier retrained per deployment. General-purpose time-series foundation models (MOMENT~\cite{moment}) cover diverse signals but lack HAR-specific inductive biases and a language label interface. Language-aligned HAR models (LanHAR~\cite{lanhar}) decouple the label interface via text similarity, but resample to a fixed rate, remain offline and segment-only, and---without a rate-invariant sensor front end---transfer unreliably across devices. No prior model is simultaneously rate-agnostic, open-vocabulary, streaming, and honestly benchmarked---the combination that a foundation model developers can build on demands.

We present HALO (\textbf{H}eterogeneity-\textbf{A}ware \textbf{L}anguage-aligned \textbf{O}pen-set model), a domain-specific IMU foundation model that enables a new deployment capability: a single pretrained model that accepts diverse wearable and phone IMU configurations---varying sampling rates, channel counts, and sensor placements---and recognizes activities via open-vocabulary cosine-similarity retrieval, both over whole recordings and as a low-latency on-device stream, with no per-dataset classifier or architectural modification required.
HALO is trained in a single language-alignment stage and rests on three design choices driven by the requirements above.
(1)~A \emph{physical-frequency filterbank tokenizer} makes the model rate-invariant \emph{by construction}: rather than resampling every dataset to a common rate (which aliases high-frequency content and fabricates samples) or maintaining per-rate input heads, HALO applies a fixed constant-Q filterbank on a fixed physical-frequency axis, computed from a native-rate transform, so the same weights read $20$--$100$\,Hz data unchanged.
(2)~\emph{Channel-independent processing with language-based sensor conditioning} handles variable sensor suites and placements: natural-language descriptions of each channel (e.g., ``accelerometer X-axis, waist-mounted phone'') are injected into the corresponding channel token to supply placement and sensor context, while the precise continuous metadata---sampling rate and window duration---is consumed numerically inside the tokenizer, since a frozen text encoder cannot represent such numbers reliably.
(3)~A \emph{streamable encoder} aligns these tokens to a frozen SentenceBERT backbone~\cite{sbert} via soft contrastive learning---soft targets derived from text--text similarity let semantically related labels (e.g., ``walking'', ``strolling'', ``ambulating'') reinforce one another, resolving the label-conflict problem inherent to multi-dataset training---while rotary position embeddings over \emph{physical time} and mixed full/causal training let one weight set run both offline and as a causal, KV-cached stream. At inference, recognition is cosine-similarity retrieval over any text label library---eliminating per-dataset classifiers.


We train HALO on 11 public HAR datasets and evaluate it on held-out datasets under a leakage-free, subject-disjoint protocol that scores each model against the target dataset's own label strings (Section~\ref{sec:experiments}), reporting macro-F1 as the primary metric.

We make the following contributions:
\begin{itemize}
  \item We frame the goal as a \emph{reusable} IMU foundation model that developers can build on, and identify the four barriers that keep prior models dataset-bound---sensing heterogeneity, open-set labels, the offline/online divide, and untrustworthy cross-dataset evaluation---from which we derive concrete design requirements: rate-agnostic tokenization, variable-channel processing, synonym-robust open-vocabulary alignment, a single model that runs both offline and as a live on-device stream, and a leakage-free evaluation protocol.
  \item We propose \textbf{HALO}, a domain-specific IMU foundation model that addresses these requirements in a single language-alignment stage. Its distinguishing components are a \emph{physical-frequency filterbank tokenizer} that is rate-invariant and anti-aliased by construction; \emph{language-based per-channel conditioning} that carries placement/sensor context in natural language while supplying sampling rate and window duration numerically; and a \emph{streamable encoder} (rotary physical-time attention with mixed full/causal training) that yields a deployment capability no prior HAR model offers: one model for both whole-session and low-latency on-device open-vocabulary recognition.
  \item We establish a leakage-free, subject-disjoint cross-dataset benchmark that scores each model against the target dataset's own label strings---removing the synonym-ontology and open-set-vocabulary artifacts of prior protocols---and package HALO behind a small \texttt{predict()} interface, so that applying it to a new device and label set takes a few lines with no classifier training or architectural change, demonstrated in an on-device iOS app. \OUTDATED{Comparative results against baselines under this protocol are being re-measured on the v2 model (Section~\ref{sec:experiments}).} We will release the pretrained checkpoint and code as a reusable foundation for mobile HAR.
\end{itemize}
