% MECHANISM diagram, not a data plot: every quantity is structural.  The
% three bars are illustrative and the caption says so.
%
% LAYOUT DISCIPLINE (learned the hard way -- a tall narrow version of this
% figure collided in six places):
%   * natural width ~7.9cm against an 8.46cm column, natural height ~4.3cm.
%     Keep the ASPECT near 1.8 or \resizebox shrinks the \tiny text to
%     illegibility.  Wide-and-short, never tall-and-narrow.
%   * three fixed bands: (A) query+memory side by side at y=0, (B) the
%     decoder sequence at y=-1.75, (C) scores at y=-2.75 and below.
%   * explanatory prose belongs in the CAPTION.  Every in-figure text node
%     costs width, and width is what squeezes the bands together.
%
% Band B is the decoder input sequence.  Group x positions are hardcoded so
% the coreference tags line up under their tokens; if you add a token, shift
% every later group by one pitch (0.31) and re-centre that group's label.
% Group gaps are wide (0.55) so the \tiny group names below do not collide.
% NOTE: keep every \\ at the top level of a node body.
% =====================================================================
