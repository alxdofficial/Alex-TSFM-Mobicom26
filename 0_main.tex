\begin{abstract}
Inertial measurement units (IMUs) are ubiquitous in phones and watches, yet human activity recognition (HAR) still has no foundation model that developers can readily build on: one pretrained model that ingests whatever sensors a device exposes, recognizes an application's own activity labels without retraining, and runs both offline over a recording and as a low-latency on-device stream. Building one is hard because IMU deployments differ in \emph{sensing heterogeneity} (sampling rates, channel suites, and placements), demand \emph{open-set} recognition of activities never seen in training, and must serve \emph{both offline and streaming} use---all under evaluation honest enough that reported gains survive leakage-free, subject-disjoint testing rather than being inflated by synonym ontologies or shared subjects.
We introduce HALO (\textbf{H}eterogeneity-\textbf{A}ware \textbf{L}anguage-aligned \textbf{O}pen-set model), a domain-specific IMU foundation model trained in a single language-alignment stage\footnote{The source code and pretrained models for HALO will be released upon acceptance.}. HALO combines three elements. First, a \emph{physical-frequency filterbank tokenizer} that is rate-invariant and anti-aliased \emph{by construction}: it reads each channel on a fixed physical-Hz axis via a native-rate transform with no resampling, so a single set of weights ingests $20$--$100$\,Hz data without interpolation or per-rate heads. Second, \emph{language-based sensor conditioning} that injects natural-language placement and sensor descriptions into each channel token, while the sampling rate and window duration---quantities a frozen text encoder cannot represent numerically---are supplied to the tokenizer as numbers rather than as text. Third, a \emph{streamable encoder} whose temporal attention uses rotary position embeddings over \emph{physical time} and is trained under mixed full/causal masks with an offline-to-online consistency objective, so one weight set serves both whole-session recognition and low-latency on-device streaming. At inference, activities are recognized by open-vocabulary cosine similarity to text labels---no per-dataset classifier. We train on 11 public HAR datasets and evaluate under a leakage-free, subject-disjoint protocol that scores against each dataset's own label strings. The result is packaged behind a deployable \texttt{predict()} interface---so a developer applies HALO to a new sensor setup and label set in a few lines, with no classifier training or architectural change---and demonstrated in an on-device iOS app. A video demonstration is available at \url{https://youtu.be/rooVKragtFU}.
