\begin{abstract}
Inertial measurement units (IMUs) are ubiquitous in phones and watches, yet human activity recognition (HAR) still has no foundation model that developers can readily build on: one pretrained model that ingests whatever sensors a device exposes and recognizes an application's own activity labels using as little labelled target data as the deployment can afford. Progress has been pursued mainly through scale, but IMU signals admit no closed grammar the way language does---a change of device orientation, mounting, or on-device filtering can place a recording outside any corpus---so more pretraining data alone does not confer compatibility. A second, subtler obstacle is that the field's standard remedy for open-set labels, projecting sensor features into a language embedding space, presumes that sensor similarity tracks linguistic similarity. It does not: \emph{drinking coffee} and \emph{drinking water} are near-identical motions but distant strings, whereas \emph{sitting} and \emph{sitting down}---a static posture and a dynamic transition---are nearly identical strings.
We introduce HALO (\textbf{H}eterogeneity-\textbf{A}ware \textbf{L}anguage-conditioned \textbf{O}pen-set model)\footnote{The source code and pretrained models for HALO will be released upon acceptance.}, which responds to each obstacle with a design choice rather than with scale. First, a tokenizer with deliberately \emph{calibrated inductive bias}: co-located axes are grouped into sensors, each read on a fixed physical-frequency axis by a constant-Q filterbank over a native-rate transform, making the model rate-invariant and anti-aliased \emph{by construction}, while sensor identity (device, modality, placement, gravity convention) is supplied as natural language so that channel count and ordering remain free. This is enough physical structure to survive unseen configurations, and few enough assumptions to compose heterogeneous corpora---in contrast to layout-locked encoders, which assume too much, and per-channel free-text models, whose conditioning can degenerate into memorising dataset provenance. Second, an \emph{evidence engine} that avoids reconciling the two geometries at all: instead of projecting sensors into label-text space, it retrieves encoded exemplars from a memory by \emph{sensor} similarity and accumulates evidence for whichever candidate labels the deployment declares at run time. Representation pretraining is entirely activity-label-free; labels enter only as annotations on retrieved memory entries.
Together these yield a single \emph{label-efficiency} curve rather than a zero-shot-versus-fine-tuning dichotomy: the same frozen model recognises declared labels with no target data, improves as a handful of demonstrated examples are appended to memory without any gradient update, and remains available for conventional fine-tuning when labels are plentiful. We train on 12 public HAR datasets and evaluate on 7 held-out datasets under a leakage-free, subject-disjoint protocol that scores against each dataset's own label strings, and package the model behind a small \texttt{predict()} interface, demonstrated in an on-device iOS app.
\end{abstract}
