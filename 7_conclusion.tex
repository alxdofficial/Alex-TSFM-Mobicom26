\section{Conclusion and Discussion}
\label{sec:conclusion}

HALO tests the proposition that acquisition configuration should calibrate evidence rather than be
normalized away. Its current encoder folds axes into physical sensors, retains frequency and
missing-information semantics, and learns without activity labels. Its classifier is a transparent
sequence of compatibility, admissibility, cosine ranking, voting, and sensor fusion. Enrollment
changes the memory rather than model parameters.

The present development result does not establish an accuracy advantage. The admissibility gate
uses enrolled examples, but it never exercises its veto and trails ungated retrieval, prototypes,
and ridge heads. This negative result narrows the next step: improve or replace the gate under
held-out physical guards before evaluating the sealed test roster. It also reinforces a broader
methodological point: a complex retrieval mechanism should not be credited when a prototype on the
same frozen features is stronger.

Other limits remain. The model classifies presegmented single-activity windows, has no unknown
output, and does not evaluate continuous segmentation or calibrated rejection. Dataset and hardware
identity are confounded in public corpora, so acquisition descriptors can become provenance
shortcuts. No deployment API or phone implementation is currently claimed. Future work should
address these limits only with versioned, reproducible artifacts and should preserve the simple
controls used here.
